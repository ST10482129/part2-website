## Project Overview

Khula Community Bakery is a fictional small bakery based in **Benoni, Gauteng**.

The website was developed to provide customers with information about the bakery, its products, services and contact details. The website also allows customers to submit enquiries and provides a responsive design for different screen sizes.

The website focuses on creating a simple, friendly and user-friendly online presence for a local community bakery.

---

## Website Goals

The main goals of the website are to:

* Establish an online presence for Khula Community Bakery.
* Display bakery products and prices.
* Provide information about the bakery and its values.
* Allow customers to make product enquiries.
* Provide clear contact information.
* Improve customer engagement.
* Provide a responsive experience on desktop, tablet and mobile devices.

---

## Website Pages

The website consists of five main pages:

1. **Home** – Introduces Khula Community Bakery and highlights featured products and values.
2. **About Us** – Provides information about the bakery, its mission, vision, values and customers.
3. **Products** – Displays available bakery products and their prices.
4. **Enquiry** – Allows customers to submit an enquiry about products or services.
5. **Contact** – Provides contact information and a contact form.

---

## Technologies

The following technologies were used to develop the website:

* **HTML5** – Used to structure the website pages and content.
* **CSS3** – Used for styling, layout, responsive design and visual presentation.
* **JavaScript** – Used for interactive features and form validation.
* **Visual Studio Code** – Used as the development environment.

---

## JavaScript Functionality

JavaScript is used to improve the interactivity of the website.

The main JavaScript features include:

* Opening and closing the mobile navigation menu.
* Changing the hamburger icon from `☰` to `✕` when the menu is opened.
* Closing the mobile menu when a navigation link is selected.
* Validating the enquiry form.
* Checking that required fields have been completed.
* Checking that email addresses are entered in a valid format.
* Displaying confirmation messages after successful form submission.
* Validating the contact form.
* Displaying the current year in the website footer.

---

## Responsive Design

The website uses responsive CSS to make the pages suitable for different screen sizes.

### Desktop

The full navigation menu is displayed across the header.

### Mobile

The navigation changes to a hamburger menu using the `☰` button. When the button is selected, the navigation links are displayed vertically.

The website uses CSS media queries to adjust:

* Navigation
* Logo size
* Page layouts
* Product cards
* Forms
* Spacing
* Typography
